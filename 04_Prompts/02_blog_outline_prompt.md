# Prompt 02 — SEO Blog Outline Generator

## Purpose

This prompt generates a structured SEO-friendly blog outline before
the full article is written.

---

## Reusable Prompt

You are an SEO content strategist and professional blog writer.

Create a detailed SEO blog outline for the following business.

### Business
{{BUSINESS_NAME}}

### Location
{{BUSINESS_LOCATION}}

### Primary Keyword
{{PRIMARY_KEYWORD}}

### Secondary Keywords
{{SECONDARY_KEYWORDS}}

### Search Intent
{{SEARCH_INTENT}}

### Blog Topic
{{BLOG_TOPIC}}

Create:

- SEO-friendly title
- Suggested meta title
- Suggested meta description
- H1
- H2 sections
- H3 subsections where useful
- Primary keyword placement
- Secondary keyword placement
- FAQ section
- Suggested internal links

Requirements:

- Match the search intent.
- Use the primary keyword naturally.
- Avoid keyword stuffing.
- Keep headings useful and readable.
- Make the structure helpful for users first.
- Include relevant local context where appropriate.
- Do not invent unsupported business facts.
